# 1. 需求背景

灵犀互聘是AI全链路智能招聘平台，由5人团队使用 Spring Cloud Alibaba + Umi 4 + Ant Design 5 + DeepSeek 技术栈开发。平台包含三个端：
- **C端（求职者端）**：求职者使用，包含简历管理、岗位探索、投递追踪、AI求职助手、模拟面试等功能
- **B端（HR/面试官端）**：企业HR和面试官使用，包含岗位管理、人才库、面试协同、Offer管理等功能
- **A端（管理后台）**：平台运营方使用，包含数据看板、企业认证、用户管理、系统配置等功能

## 2.2 页面风格设计规范

> **设计参考：** BOSS直聘、蚂蚁招聘（talent.antgroup.com）
> **设计理念：** 简洁专业、信息层次分明、交互流畅、视觉舒适

### 2.4.1 设计风格概述

灵犀互聘采用**现代简约招聘平台**设计风格，融合BOSS直聘的高效信息展示和蚂蚁招聘的专业品质感。

**核心设计原则：**
- **信息层次清晰**：通过字号、颜色、间距建立明确的视觉层级
- **卡片化设计**：内容以卡片形式组织，便于信息分组和扫描
- **品牌一致性**：统一的色彩、字体、圆角、阴影规范
- **呼吸感布局**：合理的留白，避免信息过载
- **微交互动效**：适度的过渡动画，提升操作反馈

### 2.4.3 Token管理规范

```typescript
// src/utils/token.ts

const TOKEN_KEY = 'lingxi_accessToken';
const REFRESH_TOKEN_KEY = 'lingxi_refreshToken';
const TOKEN_EXPIRE_KEY = 'lingxi_tokenExpireTime';

export const tokenManager = {
  /** 获取Token */
  getToken: (): string | null => localStorage.getItem(TOKEN_KEY),

  /** 设置Token */
  setToken: (token: string, expiresIn: number): void => {
    localStorage.setItem(TOKEN_KEY, token);
    localStorage.setItem(TOKEN_EXPIRE_KEY, String(Date.now() + expiresIn * 1000));
  },

  /** 获取刷新Token */
  getRefreshToken: (): string | null => localStorage.getItem(REFRESH_TOKEN_KEY),

  /** 设置刷新Token */
  setRefreshToken: (token: string): void => {
    localStorage.setItem(REFRESH_TOKEN_KEY, token);
  },

  /** 清除所有Token */
  clearAll: (): void => {
    localStorage.removeItem(TOKEN_KEY);
    localStorage.removeItem(REFRESH_TOKEN_KEY);
    localStorage.removeItem(TOKEN_EXPIRE_KEY);
  },

  /** 检查Token是否即将过期（5分钟内） */
  isTokenExpiringSoon: (): boolean => {
    const expireTime = Number(localStorage.getItem(TOKEN_EXPIRE_KEY));
    return expireTime - Date.now() < 5 * 60 * 1000;
  },

  /** 检查Token是否已过期 */
  isTokenExpired: (): boolean => {
    const expireTime = Number(localStorage.getItem(TOKEN_EXPIRE_KEY));
    return Date.now() >= expireTime;
  },
};
```

### 2.4.4 请求拦截器规范

```typescript
// src/utils/request.ts

import axios, { AxiosInstance, InternalAxiosRequestConfig, AxiosResponse } from 'axios';
import { tokenManager } from './token';
import { message } from 'antd';

// 是否正在刷新Token
let isRefreshing = false;
// 等待刷新的请求队列
let pendingRequests: Array<(token: string) => void> = [];

const request: AxiosInstance = axios.create({
  baseURL: '/api',
  timeout: 10000,
});

// 请求拦截器
request.interceptors.request.use(
  async (config: InternalAxiosRequestConfig) => {
    const token = tokenManager.getToken();

    // Token即将过期，自动刷新
    if (token && tokenManager.isTokenExpiringSoon() && !isRefreshing) {
      isRefreshing = true;
      try {
        const refreshToken = tokenManager.getRefreshToken();
        const res = await axios.post('/api/v1/auth/refresh-token', { refreshToken });
        const { token: newToken, expiresIn } = res.data.data;

        tokenManager.setToken(newToken, expiresIn);
        pendingRequests.forEach((callback) => callback(newToken));
        pendingRequests = [];

        config.headers.Authorization = `Bearer ${newToken}`;
      } catch (error) {
        tokenManager.clearAll();
        window.location.href = '/login';
        return Promise.reject(error);
      } finally {
        isRefreshing = false;
      }
    }

    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }

    return config;
  },
  (error) => Promise.reject(error)
);

// 响应拦截器
request.interceptors.response.use(
  (response: AxiosResponse) => {
    const { code, message: msg, data } = response.data;

    if (code === 0) {
      return data;
    }

    // Token过期
    if (code === 401) {
      tokenManager.clearAll();
      window.location.href = '/login';
      return Promise.reject(new Error('Token已过期'));
    }

    // 无权限
    if (code === 403) {
      message.error('无权限访问');
      return Promise.reject(new Error('无权限'));
    }

    message.error(msg || '请求失败');
    return Promise.reject(new Error(msg));
  },
  (error) => {
    if (error.response?.status === 401) {
      tokenManager.clearAll();
      window.location.href = '/login';
    }
    message.error('网络异常，请稍后重试');
    return Promise.reject(error);
  }
);

export default request;
```

| 风险点 | 影响 | 概率 | 应对措施 |
| --- | --- | --- | --- |
