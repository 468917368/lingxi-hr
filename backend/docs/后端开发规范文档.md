com.lingxi.{module}

### 2.2 命名规范

#### 类命名
- **Controller：** `{业务}Controller`，如 `JobController`、`UserController`
- **Service：** `{业务}Service`，如 `JobService`、`UserService`
- **ServiceImpl：** `{业务}ServiceImpl`，如 `JobServiceImpl`
- **Mapper：** `{表名}Mapper`，如 `JobPostMapper`
- **Entity：** 表名大驼峰，如 `job_post` → `JobPost`
- **DTO：** `{业务}{操作}Request/Response`，如 `JobCreateRequest`
- **VO：** `{业务}VO`，如 `JobDetailVO`

#### 方法命名
- **查询：** `get{单数}`、`list{复数}`、`count{复数}`、`search{复数}`
- **新增：** `create{单数}`、`add{单数}`
- **修改：** `update{单数}`、`modify{单数}`
- **删除：** `delete{单数}`、`remove{单数}`
- **状态变更：** `{动作}{单数}`，如 `publishJob`、`approveCertification`

#### 数据库命名
- **表名：** 小写下划线，如 `job_post`、`hr_company`
- **字段名：** 小写下划线，如 `created_at`、`updated_at`
- **主键：** `id`，BIGINT UNSIGNED
- **外键：** `{关联表}_id`，如 `user_id`、`job_id`

/**
 * 统一API响应

@Data
public class ApiResponse<T> {
    /** 状态码，0表示成功 */
    private int code;
    /** 提示信息 */
    private String message;
    /** 响应数据 */
    private T data;

    public static <T> ApiResponse<T> success(T data) {
        ApiResponse<T> response = new ApiResponse<>();
        response.setCode(0);
        response.setMessage("success");
        response.setData(data);
        return response;
    }

    public static <T> ApiResponse<T> error(int code, String message) {
        ApiResponse<T> response = new ApiResponse<>();
        response.setCode(code);
        response.setMessage(message);
        return response;
    }
}

## 4. 数据库规范

### 4.1 表设计规范

#### 基础字段
所有表必须包含以下基础字段：

```sql
`id`          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
`created_at`  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
`updated_at`  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
```

#### 软删除
需要软删除的表添加：

```sql
`deleted_at`  DATETIME COMMENT '逻辑删除时间（NULL=未删除）',
```

#### 乐观锁
需要并发控制的表添加：

```sql
`version`     INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '乐观锁版本号',
```

### 4.2 索引规范

- 主键索引：`PRIMARY KEY (id)`
- 唯一索引：`UNIQUE KEY uk_{字段名} ({字段})`
- 普通索引：`KEY idx_{字段名} ({字段})`
- 组合索引：遵循最左前缀原则

### 4.3 SQL规范

- 禁止使用 `SELECT *`，明确指定查询字段
- 禁止在WHERE条件中对字段进行函数转换
- 大表分页使用游标分页，避免 `OFFSET`
- 批量操作控制在1000条以内

<mapper namespace="com.lingxi.job.mapper.JobPostMapper">

        <result column="updated_at" property="updatedAt"/>
        <result column="deleted_at" property="deletedAt"/>
    </resultMap>

    <!-- 通用查询列 -->
    <sql id="Base_Column_List">

        salary_min_amount, salary_max_amount, salary_currency,
        total_hc, reserved_hc, confirmed_hc,
        status, version, created_by, created_at, updated_at
    </sql>

    <!-- 根据ID查询 -->
    <select id="selectById" resultMap="BaseResultMap">
        SELECT <include refid="Base_Column_List"/>
        FROM job_post
        WHERE id = #{id} AND deleted_at IS NULL
    </select>

    <!-- 根据企业ID查询 -->
    <select id="selectByCompanyId" resultMap="BaseResultMap">
        SELECT <include refid="Base_Column_List"/>
        FROM job_post
        WHERE company_id = #{companyId} AND deleted_at IS NULL
        ORDER BY updated_at DESC
    </select>

    <!-- 条件查询 -->
    <select id="selectByCondition" resultMap="BaseResultMap">
        SELECT <include refid="Base_Column_List"/>
        FROM job_post
        <where>
            deleted_at IS NULL
            <if test="companyId != null">
                AND company_id = #{companyId}
            </if>
            <if test="status != null">
                AND status = #{status}
            </if>
            <if test="keyword != null and keyword != ''">
                AND (title LIKE CONCAT('%', #{keyword}, '%')
                     OR jd_summary LIKE CONCAT('%', #{keyword}, '%'))
            </if>
            <if test="cityCode != null and cityCode != ''">
                AND city_code = #{cityCode}
            </if>
        </where>
        ORDER BY updated_at DESC
    </select>

    <!-- 插入记录 -->
    <insert id="insert" useGeneratedKeys="true" keyProperty="id">
        INSERT INTO job_post (
            company_id, title, city_code, city_name,
            min_experience_years, education_requirement,
            salary_min_amount, salary_max_amount, salary_currency,
            jd_text, total_hc, status, created_by

            #{minExperienceYears}, #{educationRequirement},

            #{jdText}, #{totalHc}, #{status}, #{createdBy}
        )
    </insert>

    <!-- 更新记录（乐观锁） -->
    <update id="updateByIdAndVersion">
        UPDATE job_post
        <set>
            <if test="record.title != null">title = #{record.title},</if>
            <if test="record.status != null">status = #{record.status},</if>
            <if test="record.jdText != null">jd_text = #{record.jdText},</if>
            <if test="record.totalHc != null">total_hc = #{record.totalHc},</if>
            version = version + 1,
            updated_at = NOW()
        </set>
        WHERE id = #{record.id}
          AND version = #{version}
          AND deleted_at IS NULL
    </update>

    <!-- 逻辑删除 -->
    <update id="deleteById">
        UPDATE job_post
        SET deleted_at = NOW(), updated_at = NOW()
        WHERE id = #{id} AND deleted_at IS NULL
    </update>

</mapper>

### 5.4 Service实现

```java
@Service
@Slf4j
public class JobServiceImpl implements JobService {

    @Autowired
    private JobPostMapper jobPostMapper;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long createJob(JobCreateRequest request, Long userId) {
        JobPost jobPost = new JobPost();
        BeanUtils.copyProperties(request, jobPost);
        jobPost.setCreatedBy(userId);
        jobPost.setStatus(JobStatus.DRAFT.getCode());

        jobPostMapper.insert(jobPost);
        return jobPost.getId();
    }

    @Override
    public JobDetailVO getJobDetail(Long jobId) {
        JobPost jobPost = jobPostMapper.selectById(jobId);
        if (jobPost == null) {
            throw new BusinessException(2101, "岗位不存在");
        }
        JobDetailVO vo = new JobDetailVO();
        BeanUtils.copyProperties(jobPost, vo);
        return vo;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void updateJob(Long jobId, JobUpdateRequest request, Long userId) {
        JobPost jobPost = jobPostMapper.selectById(jobId);
        if (jobPost == null) {
            throw new BusinessException(2101, "岗位不存在");
        }
        if (!JobStatus.DRAFT.getCode().equals(jobPost.getStatus())) {
            throw new BusinessException(2104, "当前状态不可编辑");
        }

        BeanUtils.copyProperties(request, jobPost);
        int rows = jobPostMapper.updateByIdAndVersion(jobPost, jobPost.getVersion());
        if (rows == 0) {
            throw new BusinessException(2102, "数据已被修改，请刷新重试");
        }
    }
}
```

### 5.6 分页查询

```java
@Override
public PageResult<JobListVO> listJobs(JobListQuery query) {
    // 使用PageHelper分页（必须在查询前调用）
    // pageNum: 页码（从1开始），pageSize: 每页条数
    PageHelper.startPage(query.getPage(), query.getSize());
    List<JobPost> list = jobPostMapper.selectByCondition(query);

    // 转换为VO
    List<JobListVO> voList = list.stream()
        .map(item -> {
            JobListVO vo = new JobListVO();
            BeanUtils.copyProperties(item, vo);
            return vo;
        })
        .collect(Collectors.toList());

    // 封装分页结果
    PageInfo<JobPost> pageInfo = new PageInfo<>(list);
    return PageResult.of(voList, pageInfo.getTotal());
    // pageInfo.getTotal()   = 总记录数
    // pageInfo.getPages()   = 总页数
    // pageInfo.getPageNum() = 当前页码
}
```

public void batchUpdateStatus(List<Long> ids, String status) {

### 5.8 MyBatis vs MyBatis-Plus 对照表

| 功能 | MyBatis-Plus | 原生MyBatis |
|------|--------------|-------------|
| 继承 | `extends BaseMapper<T>` | 不继承，纯接口 |
| 单表查询 | `selectById(id)` | 手写XML `<select>` |
| 条件构造 | `LambdaQueryWrapper` | XML `<where>` + `<if>` |
| 分页 | `Page<T>` + 分页插件 | PageHelper.startPage() |
| 逻辑删除 | `@TableLogic` 注解 | XML中统一加 `AND deleted_at IS NULL` |
| 乐观锁 | `@Version` 注解 | XML中 `WHERE version = #{version}` |
| 自动填充 | `@TableField(fill=INSERT)` | 手动在Service中set |
| 代码生成 | AutoGenerator | 不使用，手写 |
| Service基类 | `ServiceImpl<M,T>` | 无基类，纯实现 |

@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ApiResponse<?> handleBusinessException(BusinessException e) {
        log.warn("业务异常: code={}, message={}", e.getCode(), e.getMessage());
        return ApiResponse.error(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ApiResponse<?> handleValidException(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
            .map(FieldError::getDefaultMessage)
            .collect(Collectors.joining(", "));
        return ApiResponse.error(400, message);
    }

    @ExceptionHandler(Exception.class)
    public ApiResponse<?> handleException(Exception e) {
        log.error("系统异常", e);
        return ApiResponse.error(500, "系统内部错误");
    }
}

| Key格式 | 说明 | TTL | 示例 |

| `conversation:{id}` | 会话数据 | 30分钟 | conversation:101 |
| `unread:{userId}` | 未读数 | 持久化 | unread:1001 |

### 8.2 缓存使用模式

#### Cache-Aside模式
```java
@Override
public UserInfo getUserById(Long userId) {
    String cacheKey = "user:" + userId;

    // 1. 查缓存
    UserInfo user = redisTemplate.opsForValue().get(cacheKey);
    if (user != null) {
        return user;
    }

    // 2. 查数据库
    user = userMapper.selectById(userId);
    if (user == null) {
        return null;
    }

    // 3. 写缓存
    redisTemplate.opsForValue().set(cacheKey, user, 30, TimeUnit.MINUTES);
    return user;
}
```

### 8.3 缓存更新策略

- **主动更新：** 数据变更时同步更新缓存
- **延迟双删：** 先删缓存 → 更新数据库 → 延迟再删缓存
- **过期淘汰：** 设置合理TTL，依赖自动过期

### 12.2 悲观锁

适用于写多、冲突频繁的场景（如HC预冻结）：

```java
// Mapper接口
JobPost selectForUpdate(@Param("id") Long id);
int updateReservedHc(@Param("id") Long id, @Param("increment") int increment);
```

```xml
<!-- 悲观锁查询 -->
<select id="selectForUpdate" resultMap="BaseResultMap">
    SELECT <include refid="Base_Column_List"/>
    FROM job_post
    WHERE id = #{id} AND deleted_at IS NULL
    FOR UPDATE
</select>

<!-- 更新HC（原子操作） -->
<update id="updateReservedHc">
    UPDATE job_post
    SET reserved_hc = reserved_hc + #{increment},
        version = version + 1,
        updated_at = NOW()
    WHERE id = #{id} AND deleted_at IS NULL
</update>
```

```java
@Transactional
public void reserveHC(Long jobId, Long offerId) {
    // SELECT ... FOR UPDATE 加行锁
    JobPost job = jobPostMapper.selectForUpdate(jobId);

    // 校验并更新
    if (job.getAvailableHc() <= 0) {
        throw new BusinessException(2201, "无可用HC");
    }

    // 更新HC
    jobPostMapper.updateReservedHc(jobId, 1);
}
```

public void processWithLock(Long businessId) {
    String lockKey = "lock:process:" + businessId;
    boolean locked = redisTemplate.opsForValue()
        .setIfAbsent(lockKey, "1", 30, TimeUnit.SECONDS);

    if (!locked) {
        throw new BusinessException(429, "操作过于频繁");
    }

    try {
        // 业务逻辑
    } finally {

    }

## 15. 常见问题FAQ

### Q1: 如何处理分布式事务？
A: 优先使用本地事务+消息队列的最终一致性方案，避免使用2PC/XA。

### Q2: 如何处理Feign调用超时？
A: 配置合理的超时时间，实现降级逻辑，返回默认值或友好提示。

### Q3: 如何防止接口重复提交？
A: 使用Redis实现幂等控制，前端传入唯一流水号，后端校验并记录。
