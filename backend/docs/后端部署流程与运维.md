# 灵犀互聘 后端部署流程与运维

> 适用：2 台阿里云 ECS（8G 后端机 + 4G 前端机），后端 7 个微服务以 **`java -jar` 直接运行** 在 8G 机，基础设施用 Docker。

## 一、部署架构

| 机器 | IP（内网） | 运行内容 |
|------|------|----------|
| **8G 后端机** | `172.17.24.42` | Docker 基础设施（MySQL/Redis/Nacos/RocketMQ）+ 7 个后端服务（`java -jar`） |
| **4G 前端机** | `172.31.40.171` | nginx（前端静态页 + `/api` 反代到 `172.17.24.42:8080`） |

后端 7 个服务及端口：

| 服务 | 端口 | JVM 堆 |
|------|:---:|:---:|
| lingxi-gateway | 8080 | 384m |
| lingxi-user | 8086 | 512m |
| lingxi-chat | 8087 | 384m |
| lingxi-job | 8082 | 512m |
| lingxi-resume | 8083 | 768m（含文档解析） |
| lingxi-hr | 8084 | 512m |
| lingxi-admin | 8085 | 384m |

**连接方式**：后端服务直接连本机 `127.0.0.1` 的基础设施映射端口（3306/6379/8848/9876）；Docker 容器间用 `mynet` 容器名互通。服务注册到 Nacos 的地址是 `172.17.24.42`（通过 `SPRING_CLOUD_NACOS_DISCOVERY_IP` 指定）。

## 二、部署流程（从零到跑起来）

### 1. 本地构建（macOS，必须 JDK 8）

```bash
export JAVA_HOME=/Library/Java/JavaVirtualMachines/zulu-8.jdk/Contents/Home
cd <项目>/liuhao-talentforge/deploy
./build-jars.sh        # mvn clean package -DskipTests → 拷贝 7 个 fat jar + schema.sql
```

> 坑：默认 `mvn` 跑在 JDK 26，Lombok 1.18.30 不支持，会报"找不到符号"。必须用 JDK 8（zulu-8）。

### 2. 上传到服务器

```bash
ssh root@121.40.45.122 "mkdir -p /opt/lingxi/app"
scp -r <项目>/liuhao-talentforge/deploy/services root@121.40.45.122:/opt/lingxi/app/
# 运维脚本（可选，拷贝一次）
scp <项目>/liuhao-talentforge/deploy/{start.sh,stop.sh,restart.sh,status.sh} root@121.40.45.122:/opt/lingxi/app/
```

### 3. 基础设施（Docker，8G 机）

首次或重装时按顺序执行。**数据目录已挂载到 `/data/`，删容器不丢数据。**

```bash
# Docker 镜像加速（一次性）
tee /etc/docker/daemon.json <<'EOF'
{"registry-mirrors":["https://0x96fcce.mirror.aliyuncs.com"],"log-driver":"json-file","log-opts":{"max-size":"100m","max-file":"3"}}
EOF
systemctl daemon-reload && systemctl restart docker

# 网络 + 数据目录
docker network create mynet
mkdir -p /data/mysql /data/redis /data/rocketmq/namesrv/logs /data/rocketmq/broker/{logs,store} /data/nacos

# MySQL（首次启动前把 schema.sql 放到 /data/init/，自动建 34 张表）
mkdir -p /data/init && scp -r <项目>/liuhao-talentforge/deploy/infra/schema.sql root@121.40.45.122:/data/init/
docker run -d --name mysql --network mynet -p 3306:3306 --memory 512m \
  -e MYSQL_ROOT_PASSWORD=123456 \
  -v /data/mysql:/var/lib/mysql \
  -v /data/init/schema.sql:/docker-entrypoint-initdb.d/01-schema.sql:ro \
  --restart=always mysql:8.0 \
  --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci

# Redis（必须 --requirepass 123456，和各服务 REDIS_PASS 一致）
docker run -d --name redis --network mynet -p 6379:6379 --memory 256m \
  -v /data/redis:/data --restart=always \
  redis:7-alpine redis-server --appendonly yes --requirepass 123456

# Nacos 2.2.3（⚠ 容器内存必须 768m，512m 会 OOM 死循环）
docker run -d --name nacos --network mynet -p 8848:8848 -p 9848:9848 \
  --memory 768m -e MODE=standalone \
  -e JVM_XMS=256m -e JVM_XMX=512m -e JVM_XMN=128m \
  -v /data/nacos:/home/nacos/data --restart=always \
  nacos/nacos-server:v2.2.3

# RocketMQ NameServer
docker run -d --name rocketmq-namesrv --network mynet -p 9876:9876 --memory 256m \
  -v /data/rocketmq/namesrv/logs:/home/rocketmq/logs --restart=always \
  apache/rocketmq:5.1.0 sh mqnamesrv

# RocketMQ Broker（连接同机 namesrv）
docker run -d --name rocketmq-broker --network mynet \
  -p 10909:10909 -p 10911:10911 -p 10912:10912 --memory 512m \
  -e "JAVA_OPT_EXT=-Xms256m -Xmx512m" \
  -v /data/rocketmq/broker/logs:/home/rocketmq/logs \
  -v /data/rocketmq/broker/store:/home/rocketmq/store --restart=always \
  apache/rocketmq:5.1.0 sh mqbroker -n rocketmq-namesrv:9876
```

**基础设施初始化后必做 2 件事**：

```bash
# ① 若 MySQL 没挂 init 脚本，手动导入建表（应显示 34 张表）
docker exec -i mysql mysql -uroot -p123456 < /opt/lingxi/app/../deploy/infra/schema.sql   # 按实际路径
docker exec -it mysql mysql -uroot -p123456 -e "USE lingxi; SHOW TABLES;" | wc -l

# ② 创建 Nacos 命名空间 lingxi（不建则服务互不可见，网关 503）
sleep 40 && curl -X POST "http://127.0.0.1:8848/nacos/v1/console/namespaces" \
  -d "customNamespaceId=lingxi&namespaceName=lingxi"
```

### 4. 启动后端服务

```bash
cd /opt/lingxi/app
./start.sh        # 见下方运维脚本
```

### 5. 验证

```bash

curl -s -X POST http://127.0.0.1:8080/api/v1/auth/login -H "Content-Type: application/json" \

curl -s "http://127.0.0.1:8848/nacos/v1/ns/service/list?pageNo=1&pageSize=20&namespaceId=lingxi"
```

### 6. 前端（4G 机）

## 三、运维脚本（服务器 /opt/lingxi/app/）

| 脚本 | 作用 |
|------|------|
| `start.sh` | 启动 7 个服务（幂等，已运行的跳过） |
| `stop.sh` | 停止 7 个服务 |
| `restart.sh` | 重启（stop → sleep 3 → start） |
| `status.sh` | 查看进程 / 端口 / 基础设施容器状态 |

```bash
chmod +x start.sh stop.sh restart.sh status.sh
./start.sh       # 启动
./status.sh      # 看状态
./restart.sh     # 重启
./stop.sh        # 停止
```

> `start.sh` 里的 IP/OSS/密码都是当前环境的，若换机器需同步改。

## 四、日志与排障

```bash
# 看单个服务日志
tail -100 logs/gateway.log
tail -f logs/lingxi-resume.log

# 手动重启单个服务（如 gateway）
pkill -f lingxi-gateway/app.jar
nohup java -Xmx384m -jar services/lingxi-gateway/app.jar > logs/gateway.log 2>&1 &
```

### 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 网关 503 `Unable to find instance` | Nacos 没建命名空间 `lingxi`，或服务没注册 | 建命名空间；等 1-2 分钟让服务重连；必要时 `restart.sh` |
| 网关 503 + `Client not connected UNHEALTHY` | Nacos 重启过，网关 gRPC 连接没恢复 | 重启 gateway（`pkill -f lingxi-gateway/app.jar` 后手动起） |
| 服务起后立刻退出 | MySQL 没建表 / Redis 密码不对 / Nacos 没起 | 看对应 `logs/<服务>.log` |
| Nacos 控制台打不开 / API 空 | Nacos 容器 OOM 反复重启（内存 512m 不够） | `docker inspect nacos` 看重启次数；重建时 `--memory 768m` |
| 上传文件失败 | OSS key 失效或 bucket 不存在 | 检查 `start.sh` 里 `STORAGE_ALIYUN_OSS_*` |
| `resume` 反复重启 | RocketMQ broker 没就绪 | `docker logs rocketmq-broker`；确认 broker 起来了再启 resume |
| 接口 500（非 400） | 服务内部异常 | `tail -100 logs/<对应服务>.log` 看堆栈 |

### 踩过的坑（部署时记录）

1. **Nacos 容器内存**：`--memory 512m` 装不下 JVM `-Xmx512m` + 元空间，会 OOM 死循环（重启次数暴涨）。**必须 768m**。
2. **Nacos 版本**：用 2.2.3（匹配 Spring Cloud Alibaba 2021.0.6.0）。3.2.1 有兼容风险。
3. **Redis 必须设密码**：`--requirepass 123456`，否则各服务默认 `REDIS_PASS=123456` 会 auth 失败。
4. **MySQL 必须导 schema.sql**：`docker run` 手动起的 MySQL 不挂 init 脚本就没有表。
5. **Nacos 命名空间 `lingxi`**：不创建则 7 个服务互相发现不了，网关一律 503。
6. **启动顺序**：先基础设施（等 Nacos/MySQL/MQ 就绪）→ 再起服务。resume 依赖 RocketMQ，broker 没起它会启动失败。
7. **gateway 启动慢**：Nacos 刚起来时 gateway 最先启动可能 gRPC 连接失败标记 UNHEALTHY，导致 503；重启 gateway 即可恢复。
